# Planning employés

Site de gestion des plannings (React + TypeScript + Vite + Tailwind + Supabase).

## Démarrer
1. Copier `.env.example` en `.env` et remplir l'URL et la clé `anon` de Supabase.
2. `npm install`
3. `npm run dev`

## Base de données
Le script `supabase/schema.sql` crée les tables et les règles de sécurité (RLS).
